# 💍 Talyson & Mikaelly - Nossa Memória Eterna

Bem-vindo ao repositório do site que celebra a união e a história de amor entre Talyson e Mikaelly. Este projeto foi desenvolvido para ser um diário digital vivo, comemorando cada segundo desde o nosso "Sim" no dia 20 de novembro de 2021.

## ✨ Sobre o Projeto

Mais do que um simples código, este site é uma cápsula do tempo. Ele combina tecnologia e sentimento para manter vivas as memórias do nosso grande dia e a contagem contínua da nossa vida juntos.

### 🚀 Funcionalidades Principais

- **Contador em Tempo Real:** Uma contagem precisa de anos, meses, dias, horas, minutos e segundos desde o casamento.
- **Álbum Dinâmico:** Um slider de fotos que percorre nossos momentos favoritos.
- **Cinema Particular:** Integração com vídeo do casamento via YouTube, apresentado em um layout elegante.
- **Experiência Imersiva:** Uma "Splash Screen" (tela de entrada) com trilha sonora personalizada e efeitos visuais de corações flutuantes.
- **Performance Otimizada:** Ajustes de hardware para garantir uma visualização suave, tanto no computador quanto no celular.

## 🛠️ Tecnologias Utilizadas

Este projeto foi construído "do zero" utilizando as tecnologias fundamentais da web:

- **HTML5:** Estrutura semântica do conteúdo.
- **CSS3:** Estilização avançada com animações otimizadas para GPU e Flexbox.
- **JavaScript (Vanilla):** Lógica do cronômetro, manipulação de DOM para animações de partículas e controle de mídia.
- **Google Fonts:** Uso das fontes _Cinzel_, _Montserrat_ e a elegante _Great Vibes_ para o nome do casal.

## 📸 Prévia

O site inicia com um ar de mistério e elegância, convidando o visitante a "Abrir o Convite" para liberar a música e as memórias. O design segue uma paleta de cores sofisticada em tons de azul profundo e dourado.

## 💖 Dedicação

Este site é dedicado à minha amada esposa, Mikaelly. Que cada segundo contado aqui seja apenas o começo da nossa eternidade.
